# Gemini: выход VPS и дополнительный WARP

По проверке пользователя Gemini работает через прямой выход VPS и не работает через WARP. Для такого клиента оставьте VPS: **1 → клиент → 1 → 1**. Если WARP не нужен остальным, отключите его через меню 2. Затем переподключите Amnezia и снова откройте сайт/приложение.

WARP создает другой выход через Cloudflare. Он не является обязательным компонентом Amnezia и не гарантирует поддерживаемую геолокацию, регион аккаунта или доступность Gemini. Переустановка, новый секрет и повторная регистрация сами по себе не подтверждают, что Google разрешит доступ. Для конкретного отказа регион/аккаунт не диагностировались, ключи и cookies пользователя не запрашивались.

Коротко о практической пользе и ограничениях WARP: [отдельное пояснение](warp-purpose.md).

Общая проверка **3 → 1** проверяет серверную часть, DNS/HTTPS, AWG и WARP. Даже HTTP 200/302 не подтверждает доступность приложения для аккаунта. Действия исправления **3 → 2** устанавливают недостающие базовые зависимости или с подтверждением восстанавливают включенную managed WARP настройку; они не «ремонтируют регион» Google.

При включенном managed WARP весь IPv6 AWG блокируется. Выбранным клиентам нужен внешний IPv4 DNS. Профиль телефона, split tunnel и IPv6 вне VPN сервер не исправляет: их нужно проверить на устройстве. При выборе выхода VPS часть WARP policy для других клиентов сохраняется; полное отключение WARP делается отдельно.

Если WARP все же нужен, меню 2 определяет текущий этап. Первая настройка требует согласия и явного выбора клиентов, затем создает отдельный профиль закрепленным wgcf. Повторное включение использует сохраненные данные. Ручной импорт убран из обычного меню, системный wgcf не требуется. Наличие туннеля и правила не равно успешному клиентскому интернету.

Для российских сайтов без VPN доступен экспорт **5 → 1**, но он применяется на устройстве и может затронуть общие IP-сети. Для отдельного резерва при белых списках - OpenFlux **5 → 2**, со своим клиентом и отдельной проверкой. [Ограничения и инструкции](reserve-and-routing.md).
