## Установка на VPS

[Скачать govpn.sh из ветки с исправлениями](https://raw.githubusercontent.com/redoxprison-pixel/amnezia-warp-fix/refs/heads/fix/awg-warp-safe-persistence/govpn.sh). В `main` до объединения PR остается старая версия. Состояние изменений: [Draft PR #1](https://github.com/redoxprison-pixel/amnezia-warp-fix/pull/1).

Для Linux с Bash 4+, Python 3.8+, curl и sudo/root. Меню ориентировано на Debian/Ubuntu и может устанавливать пакеты через apt. Amnezia и Docker должны быть установлены для работы с AWG. Сначала скачайте и просмотрите скрипт. Установка ниже сохраняет предыдущий файл, если он есть:

```bash
(
    set -eu
    govpn_download=$(mktemp)
    trap 'rm -f -- "$govpn_download"' EXIT
    curl -fsSL --proto '=https' --proto-redir '=https' \
      'https://raw.githubusercontent.com/redoxprison-pixel/amnezia-warp-fix/refs/heads/fix/awg-warp-safe-persistence/govpn.sh' \
      -o "$govpn_download"
    bash -n "$govpn_download"
    if [ -e /usr/local/bin/govpn ]; then
        sudo cp -p /usr/local/bin/govpn "/usr/local/bin/govpn.before-$(date +%Y%m%d-%H%M%S)"
    fi
    sudo install -m 755 "$govpn_download" /usr/local/bin/govpn
)
```

Проверка версии: `/usr/local/bin/govpn version`. Запуск меню: `sudo /usr/local/bin/govpn`. Установка файла сама по себе не включает WARP. Запуск полного меню выполняет подготовку системы; для проверки версии используйте именно `version`.

После перехода на эту ветку обновляйте через `sudo /usr/local/bin/govpn update` или **8 → 2**. Updater делает backup и атомарную замену. Команда установки выше также подходит для разового перехода со старой версии, updater которой пока скачивает `main`. Полный путь установленного скрипта: `/usr/local/bin/govpn`.

## Имена клиентов

Главное меню **4 → Управление клиентами AWG** показывает имя и IP. Список WARP также показывает имена: **3** в режиме только Amnezia, **w** при одновременной работе с 3X-UI. Выбор выполняется по номеру строки.

Имя читается из `/opt/amnezia/awg/clientsTable` и сопоставляется по `clientId` (публичному ключу) с peers AWG. Поддерживается и старый формат таблицы. Отсутствующий или устаревший IP в метаданных больше не мешает получить имя. IP остается адресом для маршрутизации.

Если Amnezia не сохранила имя на сервере, появится `(имя не сохранено)`: определить название устройства только по IP невозможно. Откройте **4 → номер клиента → 3 → Имя в GoVPN** и задайте подпись. Она сохраняется на хосте в `/etc/govpn/client-names/<контейнер>.json` с правами 600, привязана к ключу и имеет приоритет перед именем Amnezia. Приложение Amnezia и его таблица этим действием не изменяются. Изменить имя для самого приложения можно в Amnezia.

Список обновляется при возврате в меню; в меню клиентов Enter обновляет его вручную. Время последнего handshake не является проверкой открытия сайта или гарантией, что устройство сейчас онлайн. Конфиг/QR доступен только для точного клиентского профиля, сохраненного GoVPN; профили Amnezia экспортируйте в приложении.

## WARP и проверки

WARP конфигурация и положительный список выбранных IPv4 /32 хранятся в `/etc/amnezia-warp/<контейнер>/state.json` с правами 600. Пункты установки и переустановки используют уже сохраненный профиль и список клиентов; ручной import остается доступен. Удаление активного WARP сохраняет профили и backups. Повторная регистрация WARP и прямое изменение Docker storage исключены. IPv6 AWG блокируется целиком. Обычный restart поддерживается; recreate требует установки hook в остановленный контейнер до его первого запуска.

```bash
# Только информация и помощь, без установки и сетевых изменений.
bash govpn.sh version
bash govpn.sh warp-safe amnezia-awg2 --help

# Проверки исходников.
python3 -m unittest discover -s tests -v
python3 tools/bundle.py --check
bash -n govpn.sh
```

Скрипт остается самодостаточным. Для изменения backend редактируйте `lib/awg_warp.py` или `lib/awg_clients.py`, затем выполните `python3 tools/bundle.py` и тесты. Встроенные копии проверяются тестами на совпадение.

Изолированные тесты реальных Linux routes/iptables описаны в runbook. Для них используются только временные локальные Docker контейнеры без внешней сети, синтетический профиль и dummy WARP. Они не регистрируют аккаунт и не обращаются к production VPS.

Обновление снова доступно через **8 → Система и управление → 2 → Обновить скрипт**, а также через `govpn update` и `govpn update --force`. Review-сборка получает обновления из `fix/awg-warp-safe-persistence`; старая установленная версия, которая обращается к `main`, не увидит Draft PR до объединения или разовой установки новой версии. Остальные CLI: `govpn`, `backup`, `check-update`, `rollback <файл>`. Существующие функции 3X-UI, Hysteria и MTProto остаются частью legacy manager; ограничения аудита перечислены отдельно.

Не добавляйте runtime profiles, приватные ключи, account TOML и архивы в git. Они содержат секреты. Проверенные исходные копии конфигурации на VPS и существующие резервные копии не заменяются автоматически.


WARP в меню: **1 → 3** - установить / переустановить из сохраненных данных; **1 → 4** - удалить активный WARP с подтверждением прямого выхода; **1 → 2** - заменить профиль из файла. В главном пункте **3** (или **w** в combo) выбираются конкретные клиенты. Эти действия не регистрируют новый аккаунт и не обещают изменение региона Gemini. Если Gemini работает через обычный выход VPS, включать WARP для него не требуется.
